# SkillPacket product walkthrough

[Watch the MP4 recording](skillpacket-walkthrough.mp4).

An 87-second video assembled from captures of the running application at localhost:4173 in the native Codex in-app browser on 2026-10-13. It presents the real UI states as captioned scenes rather than a continuous screen recording. There is no narration. A new Flutter pathway and demonstration packet were created; existing saved packets were retained.

The walkthrough covers:

1. Landing page and Mix, Dark and Light themes.
2. Four available career pathways.
3. Flutter pathway setup with Lagos, Nigeria and a 15-minute daily study goal.
4. The curated six-milestone roadmap.
5. Pasted Dart notes, generation and automatic device storage.
6. The packet reader and source-preview labels.
7. Quiz feedback, locally saved study progress and the device packet library.
8. Appearance, preferences and device-storage settings.

Generated packets are unreviewed development source excerpts. The preview quiz checks the packet's status rather than subject mastery. Networking remained enabled during these captures. This demonstration does not verify offline operation, installed-app or cold offline reopening, audio playback, PDF extraction, live AI generation or learner-level authentication.

`chapters.json` contains approximate chapter start times. `walkthrough-poster.png` provides a preview image.
